# Draft entries for docs/DECISIONS.md

Every deviation from a `[D]` suggestion in the docs, one line each, ready to paste.
Nothing marked `[S]` is touched.

- **Sleeper HUD chrome: light, not framed.** Replaces the open question of whether HUD clusters sit in panels — each corner cluster gets a faint radial scrim and hairline arcs instead of a mist panel, because a panel over a first-person view costs more of the maze than it buys in legibility.
- **Nightmare layout: both docks full-height.** Replaces the unspecified arrangement of §8's contents — palette docks left, Sleepers dock right, powers bar centred on the bottom edge, god view is the letterbox between; the palette is touched every few seconds and a floating panel would have to be re-found each time.
- **Colour-blind marker shapes are an option, off by default.** Replaces §11's undecided default — the four §15 colours are already colour-blind-safe and always carry a number and a name, so shapes are a second belt, not the first one.
- **Five type sizes, not a modular scale.** Replaces the open type scale — 64 / 34 / 22 / 16 / 13, where 22 is the floor for every **value** on Results or the scoreboard so it survives a 720p screen share at 0.667×. A value is anything a viewer reads off the screen: a name, a Sleeper number, a score, a delta, a time, a depth. Static column labels and section captions may sit at 13, because they name a thing rather than report one.
- **`--fg-4` is decorative-only.** Not a deviation but a rule worth recording: it lands at 3.1:1 on mist, so it may only be used above 24 px or on non-text.
- **Blocked buttons state their blocker.** Replaces plain disabled styling — a button that cannot be pressed replaces its own label with the reason ("Waiting for Dev to ready up"), which is §1.3 applied to controls rather than only to placements.
- **Sleeper colours are never text.** None of the four clears 4.5:1 on mist, so they appear only as chips, markers and strokes; the name beside them is always `--fg-1`.
- **The connector net is generated, not drawn.** Replaces per-cube artwork — one six-bit mask (top, west, north, east, south, bottom) renders the glyph, so a new cube type needs no new asset.
- **Translucency is allocated by lifetime, not by surface type.** Replaces the blanket "panels are translucent mist" of §15 — USS has no backdrop-filter and the Screen Space Overlay cannot sample behind itself, so permanent docks and bars are opaque `--ink-800` and only small transient surfaces (toasts, hover peeks, the reveal card, hint cards) keep the 72 % mist.
- **Modal scrims split into frozen and live.** Modals the player has stepped away from (Pause, Options, Round start) get one captured frame blurred once on open; modals over a running round (Tab overlay, target selector) are never blurred, because a frozen frame behind live play misreports the game. This removes any need for a custom URP render feature in the UI.
- **Tabular and lining figures come from two extra font files.** Replaces the assumption that a style property can request them — Unity exposes no OpenType switches, so `tnum` and `lnum` are frozen into `LucidInter-Tabular.ttf` and `LucidCormorant-Lining.ttf` offline and selected with the `.tabular` / `.lining` classes; prose keeps proportional figures.
- **Dashed borders are one 9-sliced sprite; the connector net does not use dashes at all.** Painter2D has no dash array and USS has no `border-style`, so dashed boxes use `dash-border.png`, and a net wall is distinguished by a fainter stroke and a missing dot — two channels, and clearer than dashes at 12 px.
- **No logo.** The repo contains no mark and the brief forbids inventing one; LUCID is set in Cormorant Garamond Light at 0.22em tracking wherever a mark would go.
- **Dark dims at two levels, not one.** Replaces the flat dim implied by §6's "dims the HUD except the timer" — non-rule chrome goes to 32 %, but the health ring and crescent lives hold at 60 %, because at 32 % they measured ~1.7:1 and §1.3 forbids hiding anything a rule depends on reading. **This one needs your sign-off; the numbers are ours, not the docs'.**
- **Sleeper chips are filled with the raw colour.** Never darkened toward the near-black numeral — an 88 % black mix put `--sleeper-3` at 4.46:1, and the number inside the chip is what keeps the four colours colour-blind-safe, so it is the one element that may never fail AA. Raw, all four clear: 8.52 / 8.32 / 5.61 / 6.27.
- **The Nightmare's name reserves a chip footprint.** The Nightmare has no Sleeper number, but the empty 32 px slot is still emitted on their scoreboard row — omitting the element outdents that one name by chip + gap, and one player is the Nightmare every round.
- **Scoreboard columns are min-width, never fixed.** A letterspaced caps header wraps inside a fixed column, and a right-aligned score escapes leftward over its neighbour while its box stays put. The label or the value sizes the column; the name column absorbs the slack.
- **The rank digit is `--fg-3`, not `--fg-4`.** At 22 px it is body text, and the highlight wash pushes `--fg-4` to 3.67:1 — WCAG's 3:1 allowance only begins at 24 px.
- **Results derives every figure from one session record.** Not a visual decision, but a rule for whoever implements the screen: the player cards, the leaderboard deltas and the badges must be computed from one source with SPEC §12 applied in code. Written as three independent literal blocks, three of four players disagreed with themselves.
