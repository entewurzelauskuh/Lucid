Thin line icon on the 24px Lucid grid; the whole icon language, including the four door states, the six powers, palette categories and ready/unready.

```jsx
<Icon name="door-exit" size={24} color="var(--exit-500)" />
<Icon name="power-molasses" size={20} />
```

Inherits `currentColor` by default, so colour it from the parent. Stroke stays 1.5 up to 40px. Never used as the sole carrier of a rule — pair with a label (UI.md §1.5).
