The only two buttons: one white-gold primary per screen, hairline secondaries for everything else.

```jsx
<Button variant="primary" size="lg">Host a dream</Button>
<Button variant="secondary" hotkey="Esc">Back</Button>
<Button variant="primary" reason="Waiting for Ben to ready up" />
```

`reason` is the pattern that matters: a blocked action states its own blocker verbatim from the UI.md §14 glossary instead of greying out silently.
