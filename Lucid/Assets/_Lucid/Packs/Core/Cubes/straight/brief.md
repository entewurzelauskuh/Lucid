# Straight

The plainest cube in the game: a corridor that runs north to south.

It exists to be the thing everything else is measured against. If a Sleeper
cannot cross this in a straight line at full speed, the kit limits are wrong;
if the Nightmare cannot chain these to push the exit deeper, the placement
rules are wrong.

- **Connectors** north and south, so it extends a run without turning it.
- **Interior** 4 m wide and 4 m high — a corridor inside the 8 m cube rather
  than an 8 m hall, so the shell reads as architecture and not as an empty box.
- **No props.** The skin provides all the character (docs/SPEC.md §16); this
  cube should look completely different in a bedroom and in a dungeon while
  being the same geometry.

Cost 1: the cheapest thing the Nightmare can build, and the baseline the
budget's tuning intent is stated against (docs/SPEC.md §10).
